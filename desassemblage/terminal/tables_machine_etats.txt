LES TABLES DE LA MACHINE A ETATS, LES DEUX BUILDS EN REGARD

Depose le 2026-11-19. Lu dans le FICHIER des deux images, en
lecture seule. Aucun jeu lance.

La STRUCTURE des deux tables a ete lue dans le code qui les
PARCOURT, pas devinee :
  X360  parcours du mode      0x822BE8C0  pas 0x58, borne 0x2C0
        parcours du sous-etat 0x822BE4CC  pas 0x14, borne 0x3AC
  APM3  parcours du mode      0x1800DA631  pas 0x68, borne 0x410
        parcours du sous-etat 0x1800DA714  pas 0x20, borne 0x37

  descripteur de MODE      X360 0x58 o          APM3 0x68 o
    +0x00 identifiant (CLEF, pas la position)   +0x00
    +0x04 fn_entree                             +0x08
    +0x08 fn_milieu                             +0x10
    +0x0C fn_sortie                             +0x18
    +0x10 CHAINE des sous-etats, 16 mots,        +0x20
          terminee par MAX (0x2F / 0x37)
    +0x50 MODE DE RETOUR quand celui-ci finit    +0x60

  descripteur de SOUS-ETAT X360 0x14 o          APM3 0x20 o
    +0x00 numero (= l index)                     +0x00
    +0x04 drapeau (0 ou 1)                       +0x04
    +0x08 fn_entree                              +0x08
    +0x0C fn_milieu                              +0x10
    +0x10 fn_sortie                              +0x18
