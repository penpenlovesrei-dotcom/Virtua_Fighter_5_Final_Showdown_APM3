#
# Le bloc de refraction est ce qui, cote console, allume la passe 3 et
# pose le drapeau que le lieur de scene relit. Il est lu :
#
#     Xbox 360 2007   [descripteur + 0x5C]   FUN_822C3E38, cas 1
#     APM3            [descripteur + 0xC8]   FUN_18018FA20
#
# CORRECTION a `analysis/decors.md` : les champs +0xC0 et +0xC8 du descripteur
# APM3 y sont nommes << descripteur sonore principal >> et << de repli >>. Ce
# sont le bloc de REFLET et le bloc de REFRACTION. La preuve est la
# correspondance instruction par instruction avec la Xbox 360, les deux
# appelant les memes cinq accesseurs dans le meme ordre.
#
# Depose le 2026-11-19 pour `analysis/eau_ring_eileen.md`.
# Les adresses X360 sont celles de `extracted/X360_VF5/vf5_x360.img`
# (Virtua Fighter 5, Xbox 360, 2007, base 0x82000000) -- PAS celles de
# `X360_FS`, qui est Final Showdown et repondrait autre chose sans
# erreur. Les adresses APM3 sont celles de
# `binaires/vf5fs-pxd-w64-Retail_APM3.dll.origine`, base 0x180000000.
