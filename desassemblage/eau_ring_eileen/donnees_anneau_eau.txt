# Les identifiants de texture de `skb POSE` ne sont pas ceux de ver.B : notre
# import renumerote l archive (voir `reference_vf5_verb_textures_rangs`).
# 11800 -> 12674, 11801 -> 12675, 11790 -> 9207, 13599 -> 9261,
# 14043 -> 9085. Les IMAGES, elles, sont les memes : memes rangs dans la
# planche, memes moyennes.
#
# Le champ +0x3D4 vaut 0x10000A80 dans les QUATRE : le bit 28 court-circuite
# le melange au repartiteur et envoie le trace dans la file OPAQUE. La
# transparence de la console ne vient donc pas de ce champ -- elle vient de
# l etat que pose le rappel de dessin de TaskEffectWaterRing.
#
# Depose le 2026-11-19 pour `analysis/eau_ring_eileen.md`.
# Les adresses X360 sont celles de `extracted/X360_VF5/vf5_x360.img`
# (Virtua Fighter 5, Xbox 360, 2007, base 0x82000000) -- PAS celles de
# `X360_FS`, qui est Final Showdown et repondrait autre chose sans
# erreur. Les adresses APM3 sont celles de
# `binaires/vf5fs-pxd-w64-Retail_APM3.dll.origine`, base 0x180000000.
