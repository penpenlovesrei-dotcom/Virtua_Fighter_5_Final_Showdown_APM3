Associer un exécutable à une jaquette

Chaque jeu a son dossier dans borne\jeux\. Deux façons de faire :

La plus simple : mets dans le dossier du jeu un raccourci Windows (.lnk) vers l'exécutable, ou le .exe, .cmd ou .bat lui-même. La borne prend le premier par ordre alphabétique et ignore les fichiers dont le nom commence par _.
Pour choisir précisément : crée dans ce dossier un fichier jeu.json :
{ "titre": "Virtua Fighter 5 FS", "exe": "D:\\Jeux\\VF5\\vf5.exe", "args": ["-fullscreen"] }
Le chemin peut aussi être relatif au dossier du jeu ; args est facultatif.
